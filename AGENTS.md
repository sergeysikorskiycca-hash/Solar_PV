# Инструкции для ИИ-агентов

## Обязательное первое чтение для New_Program

Перед началом любой работы, относящейся к папке `New_Program`, первым делом обязательно полностью прочитай файл:

`New_Program/AI_ENTRY_GATE.md`

Это обязательное условие. Не начинай анализ задачи, изучение кода или внесение изменений в `New_Program`, пока этот файл не прочитан и все применимые пункты входного контроля не выполнены.

После него прочитай `New_Program/README.md`, затем следуй инструкциям из этих файлов.

Для работы внутри вложенных папок также обязательно учитывай все расположенные там файлы `AGENTS.md`. Инструкции более глубокой папки дополняют эти правила и применяются к работе в своей области.

## Общие правила

- Работай только в существующей ветке `main`.
- Не создавай ветки и другие сущности репозитория без предварительного объяснения и явного согласия пользователя.
- Перед изменениями изучи актуальное содержимое затрагиваемых файлов и их зависимости.
- Предпочитай минимальные точечные изменения.
- Не удаляй и не заменяй существующие данные без предварительного объяснения и согласия пользователя.
- Не запускай сборку, тесты или программу без прямого запроса либо предварительного согласования.
- Не заявляй о проверках, которые фактически не выполнялись.
- Если инструкции конфликтуют или есть риск потери данных, остановись и уточни действия у пользователя.
