# Ollama Control

Русскоязычная Windows Forms программа для управления локальной Ollama.

- Проверка доступности и версии Ollama.
- Списки установленных и загруженных моделей.
- Загрузка и выгрузка выбранной модели.
- Запуск OpenCode.
- Журнал действий.
- Окно мониторинга: Ollama API и загруженные модели; процессы Windows, CPU и RAM.
- Мониторинг OpenCode: обнаружение локального HTTP API по TCP-портам процессов OpenCode (с проверкой стандартного localhost:4096), версия сервера, список сессий, статусы busy/idle и поток событий SSE.
- В потоке событий отображаются типы событий и идентификаторы сессий/инструментов; собираются только события после подключения окна мониторинга.
- Ollama API не предоставляет универсального списка активных запросов, отправленных сторонними приложениями. Поэтому загруженная модель и показатели CPU/RAM не выдаются за доказательство генерации или зависания.
- Единое окно «Настройки → Цвета интерфейса…»: настройка фона окна, панелей, полей ввода, кнопок, информационных полей и основного цвета текста. Пользовательская палитра кнопки «Добавить в набор» сохраняется между запусками и доступна во всех местах выбора цвета.
- Отдельная кнопка обновляет список моделей, загруженных в память Ollama.
- Проверка обновлений программы находится в меню «Система».
- Информационный текст можно выделять и копировать мышью, через Ctrl+C или контекстное меню.
- При первом запуске создаётся ярлык на рабочем столе, если его ещё нет.
- Настройки сохраняются в %APPDATA%\OllamaControl.

Сборка на Windows с .NET 8 SDK:
```powershell
dotnet publish OllamaControl.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Переключение модели внутри OpenCode и удаление моделей не реализованы.
