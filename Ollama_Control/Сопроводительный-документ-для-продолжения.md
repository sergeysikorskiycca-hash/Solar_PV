# Ollama Control — документ продолжения разработки

## Размещение
- Репозиторий: https://github.com/sergeysikorskiycca-hash/Solar_PV
- Единственная ветка: main.
- Папка: Ollama_Control.
- Не создавать отдельный репозиторий или ветки.

## Назначение
Небольшая русскоязычная Windows Forms программа для управления локальным Ollama. Классический интерфейс Windows, без веб-панели.

## Интерфейс
- Белый текст по умолчанию, тёмно-серый фон.
- Отдельно настраиваются TextPrimary #FFFFFF, TextSecondary #D0D0D0, WindowBackground #303030, PanelBackground #383838, InputBackground #252525, ButtonBackground #454545, LogBackground #202020.
- Настройки хранятся в %APPDATA%\OllamaControl\settings.json и не входят в пакет обновления.

## Функции
- GET /api/version, GET /api/tags, GET /api/ps.
- Загрузка через POST /api/generate с keep_alive (по умолчанию 24h).
- Выгрузка через keep_alive=0.
- Выгрузка всех загруженных моделей с подтверждением.
- Запуск OpenCode через opencode в PATH.
- Журнал и цветовые настройки.

## Ограничения
- Переключение активной модели внутри OpenCode не реализовано.
- Удаление и переименование моделей не реализованы.
- Не выполнять автоматическую выгрузку без команды пользователя.

## Автообновление и публикация
- Workflow: .github/workflows/ollama-control-release.yml.
- Только ручной запуск из main.
- Workflow автоматически увеличивает PATCH-версию в OllamaControl.csproj и коммитит её в main.
- Собирает self-contained Windows x64 EXE.
- Публикует ZIP OllamaControl-win-x64.zip в отдельный release с тегом ollama-control-windows.
- В описании релиза хранится строка «Версия программы: X.Y.Z».
- Программа проверяет версию, загружает ZIP, проверяет SHA-256, затем передаёт установку отдельному PowerShell-процессу.
- Перед заменой файлов создаётся резервная копия; при ошибке выполняется откат.
- Пользовательские настройки находятся в AppData и сохраняются.

## Текущее состояние
Начальный каркас добавлен в репозиторий. Он ещё не собран и не проверен на Windows. До первой публикации необходимо исправить возможные ошибки компиляции и проверить API Ollama, OpenCode, установку обновления и откат. Не заявлять об успешной работе до проверки на Windows.
