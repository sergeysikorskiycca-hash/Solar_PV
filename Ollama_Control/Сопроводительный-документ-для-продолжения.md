# Ollama Control — документ продолжения разработки

## Размещение
- Репозиторий: https://github.com/sergeysikorskiycca-hash/Solar_PV
- Ветка: только `main`.
- Каталог: `Ollama_Control`.
- Не создавать отдельный репозиторий или ветки.

## Назначение и технологии
Русскоязычная Windows Forms программа на C#/.NET 8 для управления локальной Ollama через HTTP API (`localhost:11434`). Поставка — автономный Windows x64 EXE.

## Функции
- Проверка версии и доступности Ollama.
- Просмотр установленных и загруженных моделей.
- Загрузка и выгрузка выбранной модели, выгрузка всех моделей с подтверждением.
- Запуск OpenCode.
- Журнал действий.
- Единое окно «Настройки → Цвета интерфейса…»: фон окна, панелей, полей ввода, кнопок, информационных полей и основной цвет текста. Все регулировки находятся в одном месте; значения сохраняются в настройках. Общая пользовательская палитра Windows ColorDialog сохраняется в `settings.json` и загружается во всех вызовах выбора цвета; новые цвета палитры сохраняются даже при отмене выбора основного цвета.
- Кнопка «Обновить модели в памяти» отдельно запрашивает `/api/ps`, не обновляя список установленных моделей.
- Проверка обновлений программы находится в меню «Система».
- Настройки хранятся в `%APPDATA%\OllamaControl\settings.json`.

## Мониторинг
- Ollama: доступность API, версия, список загруженных моделей.
- Windows: процессы Ollama, вычислительного сервера и OpenCode, их CPU и RAM.
- OpenCode API автоматически ищется среди TCP-портов, открытых процессами OpenCode; дополнительно проверяется стандартный порт 4096. Кандидат считается сервером только после успешной проверки `/global/health`.
- При обнаружении API читаются `/session` и `/session/status`: монитор показывает список сессий и серверные статусы busy/idle.
- Подключается SSE-поток `/event`; в журнале мониторинга остаются последние 20 полученных событий. Поток переподключается после разрыва. История событий до открытия мониторинга не восстанавливается.
- Ollama `/api/ps` показывает загруженные модели, но не предоставляет список активных запросов сторонних клиентов или универсальную скорость токенов для них. CPU/RAM не трактуются как доказательство генерации или зависания.

## Выделение и копирование текста
Весь информационный текст интерфейса доступен для выделения и копирования, но не редактирования. Поддерживаются выделение мышью, `Ctrl+A`, `Ctrl+C` и контекстное меню. Поля адреса сервера и времени удержания остаются редактируемыми.

## Ярлык рабочего стола
При первом запуске программа автоматически создаёт ярлык `Ollama Control.lnk` на рабочем столе текущего пользователя. Если ярлык уже существует, он не перезаписывается. При обновлении ярлык остаётся на месте и продолжает запускать EXE из каталога программы. Если Windows не позволяет создать ярлык, запуск программы продолжается без ошибки.

## Внешний вид
Тёмная тема по умолчанию. Все используемые цветовые роли собраны в одном окне «Настройки → Цвета интерфейса…». Неиспользуемые параметры цветов удалены из настроек.

## Ограничения
- Не удалять модели и не менять конфигурацию Ollama.
- Не выгружать модели автоматически без команды пользователя.
- Переключение модели внутри OpenCode не реализовано.
- Встроенного чата нет.

## Автообновление и публикация
- Workflow: `.github/workflows/ollama-control-release.yml`.
- Запускается вручную из `main`.
- Автоматически увеличивает PATCH-версию, собирает self-contained Windows x64 EXE и обновляет ZIP в отдельном GitHub Release с тегом `ollama-control-windows`.
- Обновлятор проверяет SHA-256, делает резервную копию и пытается выполнить откат при ошибке.
- Настройки пользователя в AppData не заменяются.

## Текущее состояние
Добавлен мониторинг API OpenCode: обнаружение локального сервера, версия, сессии, их состояния и SSE-события. Сборка и проверка на Windows для этих изменений ещё не выполнялись.
