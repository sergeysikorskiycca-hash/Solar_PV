Модель запускается встроенным локальным движком AnythingLLM (Lemond), а не Ollama. В AnythingLLM выбор провайдера требуется согласовать в трёх местах интерфейса. После правильной настройки модель отвечает, а команда `ollama ps` показывает пустой список.

## Схема процессов

Подтверждённая цепочка процессов во время работы модели:

`AnythingLLM.exe → lemond.exe → llama-server.exe`

- `AnythingLLM.exe` — приложение и его вспомогательные процессы.
- `lemond.exe` — локальный движок AnythingLLM.
- `llama-server.exe` — процесс, непосредственно обслуживающий модель.
- PID процессов меняются после перезапуска; ориентироваться нужно на имена и родительские PID, а не на сохранённые номера процессов.
- Наличие `ollama.exe` в списке процессов само по себе не означает, что модель загружена в Ollama. Для этого проверять `ollama ps`.

## Замер ресурсов — 21.11.2026

| Показатель | Зафиксированное значение |
|---|---:|
| `llama-server.exe`, Working Set (RAM) | 3,12 GB |
| `llama-server.exe`, Private Memory | 6,68 GB |
| RX 580, выделенная видеопамять | около 6,5 GB из 8 GB |
| Размер модели в интерфейсе AnythingLLM | 3,3 GiB |

Важно различать показатели памяти Windows:
- **Working Set** — объём страниц процесса, находившихся в физической RAM на момент замера.
- **Private Memory** — частная выделенная память процесса; это не показатель фактически занятой физической RAM.
- **Dedicated GPU memory** — занятая выделенная видеопамять. Значение около 6,5 GB было снято в Диспетчере задач Windows при проверке модели.

Эти цифры — снимок конкретного запуска, а не постоянные требования модели. Потребление меняется в зависимости от контекста, изображений и текущей генерации.

## Быстрая диагностика PowerShell

Открыть PowerShell. Команды ниже не требуют заранее знать PID.

### 1. Проверить, какие процессы AnythingLLM и локальных движков запущены

```powershell
Get-CimInstance Win32_Process |
Where-Object { $_.Name -in @("AnythingLLM.exe","lemond.exe","llama-server.exe","ollama.exe") } |
Select-Object ProcessId, ParentProcessId, Name, ExecutablePath
```

Ожидаемая цепочка для этой модели: `AnythingLLM.exe` → `lemond.exe` → `llama-server.exe`. Вспомогательных процессов AnythingLLM может быть несколько.

### 2. Измерить RAM процесса модели

```powershell
Get-Process -Name llama-server -ErrorAction SilentlyContinue |
Select-Object Id, ProcessName,
@{N="RAM_GB";E={[math]::Round($_.WorkingSet64/1GB,2)}},
@{N="RAM_Private_GB";E={[math]::Round($_.PrivateMemorySize64/1GB,2)}}
```

Если процессов `llama-server.exe` несколько, команда покажет каждый отдельно. Сопоставить нужный процесс можно по родительской цепочке из команды №1.

### 3. Проверить, загружена ли модель в Ollama

```powershell
ollama ps
```

Пустой список означает, что в данный момент Ollama не показывает загруженных моделей. Это ожидаемо при запуске Qwen3-VL через Lemond.

### 4. Проверить использование видеопамяти

Открыть **Диспетчер задач → Производительность → GPU → AMD Radeon RX 580**. Смотреть график и значение **Выделенная память GPU** во время ответа модели. Не путать выделенную память с общей (Shared GPU memory).

## Практические замечания

- Не завершать `llama-server.exe` отдельно, если требуется штатно остановить модель: закрывать/останавливать её через AnythingLLM.
- Для диагностики сначала проверить цепочку процессов, затем RAM и выделенную видеопамять.
- Не использовать `nvidia-smi`: видеокарта AMD Radeon RX 580.
- Сохранённые PID из старых выводов PowerShell не использовать — они меняются при каждом запуске.
