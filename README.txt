SOLAR PV TFT DISPLAY MOCKUPS
============================

Назначение
----------
Три самостоятельных визуальных макета интерфейса для TFT ST7789 с физическим разрешением 240×320 пикселей:

- variant-a.html — промышленный стиль: тёмная панель, крупная мощность, две строки и диагностические акценты.
- variant-b.html — минималистичный стиль: светлый экран, чистая типографика и минимум визуального шума.
- variant-c.html — SCADA: компактная мнемосхема потоков и состояния узлов.

Как посмотреть
-------------
Откройте любой HTML-файл в Firefox, Chrome или другом браузере. Сам дисплей в макете имеет точный размер 240×320 CSS-пикселей. На компьютере рядом отображаются подсказки.

Переключение экранов:
- кнопки под макетом;
- стрелки клавиатуры влево/вправо или вверх/вниз;
- Enter — следующий экран.

В каждом варианте четыре страницы: обзор, солнечные строки, энергия, состояние системы.

ВАЖНО: ЭТО ВИЗУАЛЬНЫЕ МАКЕТЫ, НЕ ПРОШИВКА
-----------------------------------------
Файлы предназначены для оценки компоновки и читаемости до переноса в прошивку. HTML/CSS/JavaScript не исполняются на TFT. В текущем этапе не менялись скетчи ESP32/ESP8266, драйвер ST7789, распиновка, библиотека Adafruit_GFX или существующая логика контроллера.

После выбора дизайна потребуется отдельная нативная реализация на C++ для ESP32 с Adafruit_GFX/ST7789 (и при необходимости U8g2_for_Adafruit_GFX). Её нужно будет согласовать с фактической структурой проекта ESP32_Admin, не заменяя рабочую прошивку макетом.

Данные и ограничения
--------------------
Все значения являются тестовыми:
- String 1: 186,4 В; 5,82 А; 1 084 Вт; 7 214,6 кВт·ч.
- String 2: 182,1 В; 4,16 А; 758 Вт; 5 631,4 кВт·ч.
- Суммарная мощность: 1 842 Вт.
- Накопленная энергия: 12 846 кВт·ч.

Поддерживаются ровно две строки. Каждая строка имеет собственную энергию независимо от участия в суммарном отображении. Никакого опроса INA226, ESP8266, ESP32 или DS3231 нет.

Целевая аппаратная платформа
----------------------------
- ESP32 — контроллер интерфейса.
- TFT ST7789 — 240×320.
- Рендеринг после утверждения макета: нативный C++ через Adafruit_GFX/ST7789.
- Управление — кнопки UP/DOWN, LEFT/RIGHT, OK, BACK согласно принятой логике проекта.
